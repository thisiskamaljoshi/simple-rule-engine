SimpleRuleEngine — System Architecture

Zero-dependency, Zero-eval Condition Parser & Inference Engine

Layer 1

Input & Memory

Working Memory (Facts) Runtime state dictionary facts = {"fever": True, "temperature": 39}
↓
Knowledge Base (Rules) Declarative rule entities Rule(conditions=[...], conclusion="Viral Fever")
Layer 2

Condition Parser

logical_parser.py Identifies operators & splits: "fever==True AND temp>=38" → [left, op, right]
↓
parser.py Extracts single comparison: temp (var) | >= (op) | 38 (val)
Layer 3

Type-Safe Evaluator

lookup_fact() Fetches state from memory: facts["temperature"] → 39
↓
convert_user_value() Dynamic type coercion: str "38" → int 38
↓
compare_values() Safe operator execution: 39 >= 38 → True (Zero eval!)
Layer 4

Inference Engine

evaluate_logical_rule() Evaluates all conditions: all([True, True]) → True
↓
fire_rule() Fires conclusion on match: Print: "Viral Fever"
🔒 Security: 100% Injection Safe ⚡ Performance: In-memory lookup 📦 Footprint: Pure Python standard library
